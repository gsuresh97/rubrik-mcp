# Rubrik MCP Plugin for AI Assistants

Connect your AI assistant to Rubrik Security Cloud. Ask natural-language questions about backup protection, ransomware detections, SLA compliance, cluster health, and recovery readiness — and get answers directly from your RSC environment.

Read-only by default. Write operations are opt-in.

**[Full documentation →](https://rubrikinc.github.io/rubrik-mcp/)**

---

Download the latest binary from [Releases](../../releases), then follow the [Getting Started](https://rubrikinc.github.io/rubrik-mcp/getting-started/) guide.

Supports Claude Code, Cursor, Windsurf, Cline, Continue.dev, VS Code Copilot, Gemini CLI, and the OpenAI Agents SDK.
