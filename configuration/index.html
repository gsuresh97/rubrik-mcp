    Tool Loading Configuration

    The plugin registers RSC tools on startup based on a set of environment variables. This page explains the available controls and the full domain reference matrix.

    How Tool Loading Works

    At startup, the plugin reads RSC_TOOL_PROFILE (and related variables) to decide which domains to register. Only tools for registered domains appear in the AI's tool list — keeping context size small and startup fast.

    Resolution order (first match wins):

    1. RSC_TOOL_PROFILE=full or RSC_FULL_COVERAGE=true → load everything
    2. RSC_TOOL_PROFILE=minimal → load investigative core only
    3. RSC_TOOL_PROFILE=zero → load nothing (use rsc_load_domain on demand)
    4. RSC_PHASES=1,2,3 → load specific phase numbers
    5. RSC_DOMAINS=vmware,aws → load specific domains by name
    6. No variables set → standard profile (investigative core only)

    RSC_EXCLUDE_DOMAINS applies after all of the above and always wins — it removes domains regardless of which profile is active.

    Environment Variables

    Variable Default Description
    RSC_TOOL_PROFILE standard Profile preset: zero, minimal, standard, or full
    RSC_FULL_COVERAGE — Set to true to load all domains (equivalent to full profile)
    RSC_DOMAINS — Comma-separated domain keys to load (e.g. vmware,aws,mssql)
    RSC_EXCLUDE_DOMAINS — Comma-separated domain keys to exclude (applied after all other rules)
    RSC_PHASES — Comma-separated phase numbers to load (e.g. 2,3)

    Profile presets

    Profile What loads
    zero Nothing — only rsc_list_domains and rsc_load_domain are registered. Use rsc_load_domain to load any domain on demand during a session. Best for scripted/automated use cases where startup latency matters.
    minimal Investigative core only: Objects, Snapshots, SLA, Jobs, Composite, and Smart tools. No cloud, virtualization, database, SaaS, or threat tools.
    standard Same as minimal. This is the default when no profile is set.
    full All domains — equivalent to RSC_FULL_COVERAGE=true.

    Domain Reference Matrix

    Use these keys in RSC_DOMAINS and RSC_EXCLUDE_DOMAINS. Both the primary key and any aliases are accepted. Parent keys (e.g. virtualization) load all subdomains; subdomain keys (e.g. vmware) load only that subdomain.

    Examples

    Load only VMware and AWS: 

    RSC_DOMAINS=vmware,aws

    Load all cloud providers but exclude GCP: 

    RSC_DOMAINS=cloud
RSC_EXCLUDE_DOMAINS=gcp

    Load everything except SaaS and threat tools: 

    RSC_FULL_COVERAGE=true
RSC_EXCLUDE_DOMAINS=saas,threat

    Zero-load startup, then load domains on demand: 

    RSC_TOOL_PROFILE=zero
    Then ask the AI: "Load VMware tools" — it will call rsc_load_domain("vmware").
